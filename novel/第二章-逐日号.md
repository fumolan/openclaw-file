# 第二章：逐日号

## 一

消息来得毫无征兆。

第二天一早，陆辰刚走进B7层的大厅，赵恒就迎面堵住了他，脸上的表情像见了鬼。

"出大事了。"赵恒压低声音，把一个全息投影仪放在陆辰面前，"逐日号回来了。"

全息画面上是苍穹外部监控的实时影像。一艘巨大的飞船正在穿越大气层外缘，船体表面布满了烧伤和凹陷，像一头从暴风雨中挣扎归来的鲸。那是"逐日号"——苍穹计划直属的采集舰队旗舰，半年前出发前往太阳系边缘执行火魄采集任务。

"提前了四十天。"赵恒说，"原定行程还有四十天才回来，但它现在已经在近地轨道了。"

"出事了？"陆辰问。

"不知道。舰长发了紧急通讯，说有'重大发现'需要立刻汇报，但具体内容保密级别极高。"赵恒看了陆辰一眼，"韩墨白点名要你去A1层。"

陆辰没有说话。他看着全息画面里那艘伤痕累累的飞船，心跳不由自主地快了半拍。

逐日号。他父亲曾经服役的船。

---

A1层作战室比昨天更拥挤。除了韩墨白和苏晚晴，大厅里还多了几个穿太空军制服的军官，以及几个陆辰不认识的人——看工牌都是架构委员会的高级工程师。

但最先引起陆辰注意的，是大厅中央悬浮的一个全息投影。

那是一块晶体。深红色，大约拳头大小，表面有火焰般的纹路在缓慢流动，散发出一种温暖而危险的光芒。即使隔着全息投影，陆辰都能感觉到一种说不清的压迫感。

火魄。

他见过火魄的影像和照片，但从未见过实物。地球上只有苍穹核心能源舱里才有火魄的存量，普通工程师连靠近的资格都没有。

"这是逐日号带回来的样本之一。"韩墨白走过来，站在陆辰旁边，"但这次采集到的火魄……和以前不一样。"

"不一样？"

"你自己看。"韩墨白把一个数据面板递给陆辰。

屏幕上是一组能量分析数据。陆辰扫了一眼，眉头立刻皱了起来。火魄的能量释放曲线通常是平滑的——稳定、持续、可控。但这次的数据完全不是：能量输出像心电图一样剧烈波动，峰值和谷值之间的差距超过了正常范围的三倍。

更诡异的是，这些波动不是随机的。

"有规律。"陆辰说。

苏晚晴从另一侧走过来，看了一眼陆辰手里的数据，微微点头。"你注意到了。波动的频率和振幅呈现某种重复模式，像是……编码过的信号。"

"火魄在发送信号？"

"不。"苏晚晴摇头，"火魄本身的能量波动确实是异常的。但在这些波动之外，逐日号的通信系统在穿越小行星带时捕获了另一段信号——来自太阳系外。"

她调出另一个数据面板。屏幕上是一串密密麻麻的二进制数据，看起来毫无意义。

"这段信号被层层加密了。"苏晚晴说，"我已经破解了最外层的编码格式——是标准的字节码结构。"

"字节码？"陆辰接过话头，目光锐利起来。

"对。Java字节码。准确地说，是JVM-Ω格式的字节码。"

大厅里安静了一瞬。

一段来自太阳系外的信号，封装成了Java字节码格式。这意味着什么？发送者不仅了解Java虚拟机的架构，而且对JVM-Ω的特定格式了如指掌。

"发信者可能是人类。"韩墨白说出了所有人心中最不安的猜测。

"也可能不是。"苏晚晴的语气很平，"但不管是谁，它对JVM架构的了解程度，超出了我们的预期。"

## 二

解码工作在作战室的一角展开。

苏晚晴负责主导，陆辰被韩墨白指派为技术协助。理由很充分：昨天刚用"深海"追踪过苍穹系统内部的类加载链，对JVM-Ω的底层结构最熟悉。

林小溪也跟来了。她没有被邀请，但一大早就出现在A1层门口，说"赵组长让我来送数据"。赵恒当然没说过这种话，但韩墨白看了她一眼，没赶人。

"信号被分成了多层。"苏晚晴在大屏幕上调出结构图，"每一层都用了不同的加密方式，而且这些加密方式都对应着JVM-Ω的一个核心机制。要解开它们，就得对这些机制有深入理解。"

她指着最外层："第一层，类加载验证。"

JVM-Ω的类加载过程分为几个阶段：加载、链接、初始化。其中链接阶段又细分为验证、准备和解析。验证阶段是JVM的安全门户——它检查字节码是否符合规范，有没有恶意构造，格式是否正确。如果验证不通过，直接抛出VerifyError，拒绝加载。

"第一层加密模拟的就是这个验证过程。"苏晚晴解释道，"信号被封装成了一个'类文件'的结构，但其中有大量不符合规范的字段。我们需要找到这些不规范的地方，修复它们，让信号能'通过验证'。"

"这就像是在修复一个损坏的class文件。"陆辰理解了。

"没错。但复杂得多。"苏晚晴把数据推过来，"开始吧。"

陆辰打开"深海"，开始逐字节分析那段信号。

信号的结构确实模仿了JVM-Ω的类文件格式：开头是魔数（Magic Number）——每个class文件都以0xCAFEBABE开头，这是Java的签名。然后是版本号、常量池、访问标志、类索引、字段表、方法表、属性表。

但这个"类文件"到处都是陷阱。常量池的索引指向了不存在的条目，方法表的代码偏移量溢出，属性表的长度字段和实际数据不匹配……

"发信者在考验我们。"陆辰低声说，"这些错误不是随机的，每一个都对应着JVM验证阶段的一个检查点。答对了，信号就解开一层。"

林小溪凑过来看了一会儿，突然说："常量池里那些看起来像乱码的字符串，会不会是坐标？"

陆辰看了她一眼。这姑娘的直觉不错。

他重新检查常量池。在修复了几个索引错误后，常量池里的数据开始变得可读。果然，有几个条目是数值型的——看起来像是空间坐标。

"先记下来。"苏晚晴说，"继续往下。"

第二层加密更复杂。它涉及链接阶段的"解析"——将常量池中的符号引用替换为直接引用。在正常的JVM运行中，这是类加载器自动完成的工作。但在这里，符号引用和直接引用之间的映射关系被加密了，需要手动推导。

陆辰和苏晚晴花了两个小时破解这一层。林小溪在旁边打下手，负责记录数据、比对结构。她的进步速度很快，到了后半段，已经能独立识别出一些常见的加密模式。

"最后一层了。"苏晚晴看着屏幕上剩余的数据。

最后一层对应的是类加载的"初始化"阶段——执行类的静态初始化块。这段信号在初始化块中嵌入了一段逻辑：它需要输入一个特定的值，这个值必须满足一系列数学约束条件，才能触发正确的初始化流程。

"这不像是在破解加密。"陆辰盯着那些约束条件，"这像是在做一道题。"

"也许就是。"苏晚晴说。

陆辰的"深海"自动推导了约束条件，给出了可能的解空间。他逐个验证，在第七次尝试时，找到了正确的值。

屏幕上的数据突然流动起来。乱码和噪声消退，露出了一段清晰的信息。

一段坐标。指向太阳系外某个方向。

以及一句话。用标准的人类语言写成的、简简单单的一句话。

**"你们不是第一批。"**

## 三

作战室的气氛变得凝重。

韩墨白盯着那句话看了很久，然后转身离开了。几分钟后，周明远出现在大厅门口。他的表情一如既往地平静，但陆辰注意到他走进来时，右手无意识地攥了一下拳。

"信号内容保密。"周明远扫视全场，"在场所有人，从现在起不得向任何人透露。苏晚晴，你把破解过程和数据全部移交给我。"

苏晚晴没有动。"信号还没有完全破解。那段坐标指向的具体位置，还需要进一步分析——"

"不需要了。"周明远打断她，"我会安排专门的团队处理。"

苏晚晴看了韩墨白一眼。韩墨白面无表情地站在一旁，没有说话。

陆辰感觉到空气中有一根无形的线在收紧。周明远在封锁信息，而韩墨白在沉默中选择了一种微妙的立场——他没有帮周明远说话，但也没有反对。

"我可以走了吗？"陆辰问。

周明远看着他，似乎在衡量什么。"你回去继续监控昨天那个影子系统。有任何变化，第一时间报告。"

陆辰点头，收起"深海"的加密存储卡，转身往外走。

经过林小溪身边时，她小声说："那句话……'你们不是第一批'，是什么意思？"

陆辰没有回答。他也不知道答案。但他有一种直觉——这句话说的不只是"在我们之前还有其他文明"，而是更具体、更危险的意思。

也许，在人类之前，已经有很多文明被"评估"过了。而它们现在在哪里？

---

回到B7层，陆辰没有回到自己的工位，而是径直走向走廊尽头的一间小型服务器室。这是他给自己留的私人工作空间——"深海"的主节点部署在这里，比在公用服务器上安全得多。

他关上门，插入加密存储卡，启动"深海"。

屏幕上，影子系统的监控数据在安静地流动。那个方云深留下的无名模块还在运行，依然在以每分钟三到四个的速度生成新的类。远远低于昨天危机时的每秒上千个，但从未停止。

陆辰调出昨天保存的数据——包括那个自定义ClassLoader的完整追踪记录、影子系统的内部结构、以及最底层方云深留下的那行注释。

他现在可以更仔细地看了。

影子系统的核心是一个精密的内存管理模块。它在方法区中开辟了一块独立的空间，像是一个气泡——外部是苍穹系统的正常内存区域（堆、栈、方法区、程序计数器），内部则是它自己的小世界。

这个小世界有自己的类加载器、自己的对象分配策略、自己的……垃圾收集器。

"它有自己的GC。"陆辰低声说出这句话时，自己都觉得荒谬。

苍穹系统的GC是全局统一的，负责回收整个JVM-Ω内存空间中的无用对象。但影子系统内部的GC是独立的——它只管自己那个"气泡"里的对象，而且它的策略和苍穹系统的完全不同。

苍穹系统用的是G1收集器的远代演进版本，兼顾吞吐量和停顿时间。而影子系统的GC……

陆辰仔细分析了它的回收模式，发现它采用的是一种极其激进的策略：对象的存活时间被严格控制，一旦超出阈值，无论是否还有引用，都会被强制回收。就像一个独裁者，定期清洗自己的领地，不允许任何东西存在太久。

"它在隐藏什么。"陆辰得出了结论。

一个不允许对象长期存在的GC策略，意味着它在刻意阻止信息在内存中积累。如果有什么东西被写入内存，很快就会被抹掉——除非它被特别标记为"不可回收"。

就像昨天那些循环引用的对象。它们被标记为"存活"，不是出于业务需要，而是因为它们承载着某种信息——方云深想要保留的信息。

陆辰开始追踪那些被"保护"的对象。他写了一个小脚本，通过"深海"直接读取影子系统的内存空间，把所有不可回收的对象dump出来。

数据量不大。三天来被保护的对象只有四十多个。陆辰把它们一一打开，发现每个对象都是一个简单的数据容器——里面存放着一段字节码。

四十多段字节码。单独看，每段都短得没有意义。但如果把它们按照时间顺序排列……

陆辰用了十秒钟排列完，又用了五秒钟理解了结果。

那些字节码，按照时间顺序拼接在一起，组成了一个完整的方法体。一个Java方法——准确地说是JVM-Ω的字节码方法。

他在脑海中把这段字节码反编译成了伪代码：

```
void reveal() {
    String message = "如果你正在读这段代码，说明时机到了。";
    String target = decode(_COORDINATE_FROM_SIGNAL);
    navigate(target);
}
```

陆辰的手指在键盘上停住了。

`decode(_COORDINATE_FROM_SIGNAL)`——这个参数指向的是今天刚刚从逐日号信号中破解出的那段坐标。

方云深在十年前就在苍穹系统里埋下了这段代码。而它的触发条件，是有人破解了来自星系深处的信号。

他知道。他早就知道信号会来。他甚至知道信号会被封装成字节码格式。

陆辰的后背泛起一层冷汗。

他迅速检查了那段字节码的更多细节。`navigate(target)`方法不存在于苍穹系统的任何已注册类中——它是未实现的。像是一个占位符，等着有人来填。

等着他来填。

"陆辰？"

门外传来敲门声。他关掉"深海"的界面，打开了门。

是苏晚晴。她换了一身便装，但右手义体的金属关节在走廊灯光下依然醒目。

"有话说？"陆辰问。

"逐日号的火魄样本出现了新的异常。"苏晚晴直截了当，"能量波动在加剧，而且波动的频率和苍穹系统内部的某些运行参数产生了共振。"

"什么参数？"

"GC频率。"苏晚晴说，"当火魄能量波动达到峰值时，苍穹系统的GC活动也同步达到峰值。两者之间的相关系数超过了0.97。"

陆辰沉默了一会儿。

火魄的能量波动和苍穹系统的GC频率同步——这意味着物理世界和软件世界之间存在某种联系。火魄不只是能量晶体，它还在某种层面上影响着JVM-Ω的运行。

"这不可能。"他说，但声音没有底气。

"我也觉得不可能。"苏晚晴看着他，"但数据不会说谎。"

她顿了一下，然后说出了一句让陆辰彻底怔住的话：

"而且，逐日号舰长汇报了一件事。他们在小行星带采集火魄时，发现了一处异常的火魄矿脉。那些火魄的内部纹路……不是天然的。像是被刻上去的。"

"被刻上去的？"

"对。舰长说，那些纹路放大后看，像是某种文字或代码。排列方式……很像字节码指令。"

火魄内部的纹路像字节码。太阳系外的信号是字节码。苍穹系统内部的影子系统留下的是字节码。

所有的线索都指向同一个方向。

陆辰想起了父亲。十年前，他驾驶逐日号前往小行星带采集火魄，然后失踪了。

如果他也看到了那些纹路呢？如果他发现了火魄和字节码之间的联系呢？

"苏晚晴。"陆辰开口，声音很轻，"你相信有一种文明，可以把代码刻在物质的最底层吗？"

苏晚晴看着他，右手的金属手指无意识地弯曲了一下。

"在三天前，我不信。"她说，"现在，我在重新考虑。"

走廊尽头，苍穹防护网的微光透过天窗洒进来，像一层淡蓝色的薄纱。在穹顶之下，没有人见过真正的星光。

但此刻，陆辰第一次觉得，那层保护他们的穹顶，更像是一层牢笼的壁。

而牢笼之外，有什么东西正在等待。
