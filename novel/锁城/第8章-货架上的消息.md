# 第八章 货架上的消息

程锁从第三段出来的时候，天已经黑了。

他没有直接去找卫澜汇报。不是不想——是需要先处理一件更紧急的事。沈池的通讯器在他离开第三段的时候响了三次，他一直没接。第四次响的时候，他接了。

"程锁！"沈池的声音几乎是在喊，"出事了！我的队列堵了！"

"什么意思？"

"物资队列——龚齐管的那个——彻底堵死了！从今天下午开始，所有出队操作全部卡住。我的工人去领物资领不出来，全都堆在队列出口等着。"

"龚齐怎么说？"

"他不肯跳过堵塞的任务！他坚持先进先出！"

程锁挂断通讯，快步赶往龚齐的物资队列。

物资队列在堆区商业带的北区，是一个巨大的长条形仓库。仓库的一面是入队口——任务和物资从这里进入队列。另一面是出队口——工人们从这里领取任务和物资。

正常情况下，入队口和出队口同时运作，物资流畅地通过队列。但程锁到达时，出队口前面已经聚集了上百个焦急的工人。

"龚齐！"程锁在人群中找到了队列的守护人。

龚齐站在出队口的控制台前，脸色铁青。他是个中年男人，身材敦实，说话慢条斯理——平时是出了名的好脾气。但今天他的眉头拧成了死结。

"程锁，你来正好。"龚齐的声音比平时快了两倍，"出队操作卡在第五个位置。队列前面五个任务，前四个已经正常出队了，第五个——"

"第五个怎么了？"

"它不会完成。"龚齐指着控制台上的状态面板，"第五个任务的状态是'执行中'，但执行它的线程人——已经消失了。"

程锁看向面板。队列的状态显示得很清楚：

- 任务1：已完成 ✓
- 任务2：已完成 ✓
- 任务3：已完成 ✓
- 任务4：已完成 ✓
- 任务5：执行中（线程人：编号87-F，状态：不存在）✗
- 任务6：等待中
- 任务7：等待中
- ……（后续等待任务：217个）

"执行任务5的线程人不存在了？"程锁问。

"他在今天凌晨的停顿中消失了。"龚齐咬着牙说，"任务被分配给了他，他开始执行，然后停顿来了。停顿结束后，他不见了，但任务的状态没有变回来。它卡在了'执行中'。"

"你手动把状态改回来不就行了？"

"不行。"龚齐摇头，语气固执，"队列的规则是先进先出。如果任务5没有正常完成或失败退出，我不能跳过它。后面的所有任务必须等它处理完才能依次出队。"

"龚齐，"程锁压着火气，"后面有两百多个任务等着。有些是沈池的工人的口粮。你不能因为一个死任务让所有人都等着。"

"规则就是规则。"龚齐抬起头，看着程锁的眼睛，"如果我跳过任务5，那我就破坏了先进先出的原则。今天跳过一个，明天就能跳过两个。到后来谁还排队？直接插队算了。"

"那你打算怎么办？等那个消失的线程人回来？"

"我打算找到任务5的原始定义，看它到底在执行什么操作。如果我能理解它的逻辑，也许能手动触发它的完成或失败。"

程锁深吸了一口气。龚齐不是不通情理——他只是太死板。但这种死板在正常情况下是优点：正是他严格执行先进先出，物资队列才能稳定运转。

"给我看看任务5的内容。"程锁说。

龚齐调出了任务5的详细定义。程锁扫了一遍，脸色变了。

任务5的操作内容：进入堆区老年代，找到指定地址的对象，增加其引用计数。

"又是引用计数。"程锁低声说。

"什么？"龚齐没听清。

"这个任务——和第三段里的那个CAS计数器有关。"程锁指着任务定义中的地址，"它要操作的对象，就在老年代中那些泄漏对象的中心区域。"

"你的意思是——这个任务本身就是问题的一部分？"

"对。"程锁说，"有人通过沈池的线程池提交了大量标记任务。那些任务的目的是给老年代的泄漏对象添加引用。任务5是其中一个。执行它的线程人在停顿中消失了，但任务的操作已经部分执行了——引用计数已经增加了，但任务没有返回完成信号。"

"所以它卡在了中间状态。"

"对。而你的队列不肯跳过它——"

"因为规则不允许。"

程锁看着龚齐固执的脸。在正常情况下，他会尊重龚齐的规则。但现在不是正常情况。

"龚齐，"程锁换了个思路，"如果我不要求你跳过任务5，而是要求你正确地完成它呢？"

"怎么完成？执行它的线程人已经不在了。"

"任务5要增加指定对象的引用计数。如果这个操作已经完成了——引用计数已经增加了——那任务5本质上已经执行成功了。它缺的只是一个完成信号。"

龚齐想了想。"你的意思是——我手动给它发送完成信号？"

"不是你。是任务的原始提交者。"程锁说，"如果我找到任务5的提交者，让他确认操作已经完成，你就能让任务5正常退出。"

"但我不知道谁提交了这个任务。"

"我知道。"程锁说。

他没有继续解释。他转向出队口外面那些焦急等待的工人。

"各位，给我一个小时。"程锁提高了声音，"一个小时内，队列会恢复。"

工人们将信将疑地散开了。龚齐看着程锁的背影。

"你去哪？"

"第三段。"程锁说，"老段在那里。任务5是他通过线程池提交的。让他确认完成——或者让他亲眼看看他的操作造成了什么后果。"

他快步离开了物资队列。

身后，龚齐看着控制台上那个卡住的"执行中"状态。他把手放在面板上，手指沿着任务5的编号边缘轻轻划过。

"先进先出。"他低声说，"老规矩不会变。"

但他知道，如果程锁在一个小时内拿不回来完成信号，他就要面对两百多个愤怒的工人和一个彻底失效的队列。

先进先出是规则。

但规则能不能撑住，得看人。
