# 第六章：破壁

## 一

安全审查没有持续太久。

不是因为审查本身简单，而是因为在审查进行到第二天时，苍穹系统再次出事了——这次比之前任何一次都严重。

所有安全审查被中止。周明远亲自下达了命令：全员回到岗位，应对新一轮系统异常。

但陆辰知道，这次不是普通的系统异常。

因为韩墨白在审查结束时，趁人不注意，把一个数据包塞进了他的加密存储卡里。数据包里只有一行字：

**"方云深的信标不止两个。第三个在安全组的服务器上。去找到它。"**

---

安全审查持续的一天半里，陆辰表面上配合——回答问题、提交操作日志、解释他用"深海"做过的每一个操作。实际上他的大脑一直在转：方云深在苍穹系统里到底埋了多少东西？

影子系统是第一个。幽灵线程是第二个。那么第三个、第四个、第五个呢？

韩墨白说"信标"不止两个。信标——这个词用得很有意思。不是"后门"，不是"漏洞"，而是"信标"。信标是用来指引方向的。方云深留下这些信标，是为了给某个后来者指路。

给他指路。

陆辰盯着安全组的服务器集群，心里盘算着怎么进去。苏晚晴负责安全组，她的服务器等级比B7层高出三个级别，普通工程师连靠近都不行。但现在全员应急，安全组的人都被调走了——包括苏晚晴自己。

他找到林小溪。

"我需要你帮我做一件事。"

林小溪看着他，没有犹豫："什么事？"

"帮我看着走廊。如果有人来，敲三下门。"

林小溪眨了眨眼："你要黑进安全组的服务器？"

陆辰没有否认。

"我去。"林小溪说完，又补了一句，"但你欠我一个解释。"

---

安全组的服务器室在A2层。门禁是指纹加虹膜认证，但陆辰不需要破门——他只需要通过网络接入。

他在走廊的终端上启动了"深海"，开始扫描安全组服务器的端口。

然后他看到了第一个陷阱。

安全组的外围防护不是简单的防火墙——它是一整套注入式防御系统。任何外部请求都会被解析为类似SQL语句的格式，然后在防护层中执行验证。如果请求格式不符合预期，就会触发一个类似SQL注入的攻击——反向攻击入侵者。

"它在试图注入我的系统。"陆辰盯着屏幕上涌来的攻击数据，嘴角微微抽动。

这个防御系统的设计思路来自SQL注入攻击的逆向运用。在传统的Web安全中，SQL注入是最常见的攻击手段——攻击者在输入框里填入精心构造的SQL片段，使得后端数据库执行了非预期的查询。比如在登录页面输入 `" or ""="`，就能绕过密码验证。

安全组的防御系统把这个思路反过来用：它把所有外部请求当作潜在的"注入攻击"来解析，如果发现请求中包含可疑的模式，就不只是拒绝——它会构造一个反向注入，试图在入侵者的系统中执行恶意代码。

"以攻为守。"陆辰评价道。

他需要绕过这个防御。方法很明确：不要尝试强行突破，而是发送一个"干净"的请求——格式完全合规，不含任何可被解析为注入的内容。

但问题在于，他不知道什么格式才是"合规"的。安全组的通信协议是他没见过的。

陆辰花了二十分钟分析防御系统的注入模式。它检查的模式包括：引号闭合、布尔表达式注入、联合查询注入、堆叠查询注入——所有SQL注入的经典手段。这意味着，合规的请求格式是一种类似参数化查询的结构：输入不直接拼接到查询语句中，而是作为独立参数传递。

他构造了一个纯参数化的请求，发送过去。

防御系统没有触发反注入。请求通过了。

但第二层防护立刻启动了。

## 二

第二层防护是一个反序列化陷阱。

Java的序列化机制允许将对象转换为字节流，方便存储和传输。反序列化则是将字节流恢复为对象。这个机制在很多场景中都有使用——远程方法调用（RMI）、分布式通信、数据持久化。但它也是Java安全问题的高发区。

反序列化漏洞的原理很简单：当系统反序列化一个不受信任的字节流时，攻击者可以在字节流中嵌入恶意构造的对象。如果这个对象的类定义中包含了某些特殊的"魔法方法"——比如readObject()——反序列化时会自动调用这些方法，执行任意代码。

安全组的第二层防护正是利用了这一点。它把所有通过第一层防护的请求包装成一个序列化对象，然后尝试反序列化。如果请求中包含了恶意的序列化数据，反序列化时就会触发陷阱——把入侵者的IP地址、操作记录全部打包发送给安全组。

陆辰差点中招。他在请求中嵌入了一段自定义的探测代码，这段代码在反序列化时被触发，差点把他的位置暴露出去。

幸好"深海"的反序列化过滤器在最后一刻截住了它。

JVM-Ω支持反序列化过滤机制——一个白名单/黑名单系统，可以在反序列化之前检查对象的类名，决定是否允许。陆辰的"深海"配置了一个严格的白名单，只允许反序列化已知安全的类。那段恶意构造的代码不在白名单中，被自动拦截。

陆辰深吸一口气。他重新构造了请求——这次不包含任何自定义对象，只有最基本的数据查询。

请求通过了第二层。

然后是第三层。

第三层是一个完全不同的东西——不是技术陷阱，而是一道逻辑题。

屏幕上显示出一段文字：

**"以下代码片段中，哪一行存在安全漏洞？修复它，将修复后的代码作为密钥提交。"**

```java
public class SecureHandler {
    private String sessionToken;
    
    public void processRequest(String input) {
        try {
            executeCommand(input);
        } catch (Exception e) {
            throw new RuntimeException(
                "Error processing: " + e.getMessage()
            );
        }
    }
    
    private void executeCommand(String cmd) {
        Runtime.getRuntime().exec(cmd);
    }
}
```

陆辰几乎是立刻看出了问题。

两个问题。

第一，`executeCommand`方法直接将用户输入传给`Runtime.exec()`——这是典型的操作系统命令注入。如果用户输入是 `ls; rm -rf /`，系统会忠实地执行删除命令。修复方式是永远不要将未过滤的用户输入直接传给系统命令。

第二，`catch`块中将异常信息直接拼接到RuntimeException的消息里——这会暴露系统内部信息。在安全场景中，异常信息可能包含文件路径、数据库结构、甚至密钥等敏感内容。

他写下了修复方案：对输入进行白名单验证，只允许特定格式的命令；在异常处理中不暴露内部细节，只返回通用错误信息。

提交。

屏幕闪了一下，然后弹出一段数据——方云深的第三个信标。

这个信标不是代码，而是一段加密的路径。路径指向安全组服务器深处的一个隐藏存储区。

陆辰沿着路径找到了存储区。里面是一个完整的密钥片段——不是方云深一个人的，而是三个人的。

三个密钥片段，三个签名。

第一个签名：**方云深**。

第二个签名：**陆远征**。

第三个签名：**韩墨白**。

陆辰的手指僵在键盘上。

韩墨白不只是"知道"方云深留下的东西——他是参与者。他也是信标的创建者之一。

## 三

走廊里传来三声敲门声。

陆辰迅速关闭"深海"的界面，站起身来。

门开了，但站在门外的不是林小溪。

是苏晚晴。

她的表情很复杂——愤怒、理解、还有一种陆辰读不太懂的疲惫。

"你以为我不知道你在做什么？"她说。

陆辰没有说话。

"安全组的外围防护日志，你绕过了两层。"苏晚晴走进来，关上门，"第三层的逻辑题也是我设计的。你的答案是对的。"

她停顿了一下。

"方云深留下的那些信标，我三年前就发现了。"

陆辰抬起头。

"三年前，我试图打开它们。"苏晚晴说，声音很平，像是在叙述一件别人的事，"但我失败了。不是因为技术不够——是因为打开信标需要触发一个安全机制，那个机制的响应速度超出了人类操作员的极限。我的义体……"

她抬起右手，金属关节在灯光下无声地弯曲。

"就是在那次尝试中失去的。不是外部攻击——是方云深设计的防御机制失控。它不只是在保护信标，它在测试打开信标的人。我没能通过它的测试。"

苏晚晴看着陆辰。

"但你不一样。你有'深海'。你的工具可以在毫秒级别操作JVM-Ω的底层状态。三年前我用手动操作需要七秒才能完成的动作，你的'深海'零点三秒就能完成。"

"所以你在等。"陆辰说，"你在等一个能通过测试的人。"

苏晚晴没有否认。

"那你为什么不自己来？"陆辰问。

"因为周明远在盯着我。"苏晚晴的声音突然变冷，"三年前那次事故之后，他把我调到了安全组——名义上是升职，实际上是监视。我每一步都在他的眼皮底下。我不能轻举妄动。"

她看着陆辰的眼睛。

"但你不一样。你只是一个底层工程师，不在他的监视名单上。至少……前五天不在。"

"现在呢？"

"现在你在了。"苏晚晴说，"所以我们需要快。"

"快什么？"

"打开方云深的遗产。全部的。"

她从口袋里掏出一个数据芯片——和韩墨白给的那块一模一样。

"这是韩墨白的密钥片段。你有方云深和你父亲的。三个片段，三个信标创建者的签名。把它们合在一起，就能打开方云深在苍穹系统中留下的最终遗产。"

陆辰看着她手里的芯片。

"韩墨白给你的？"

"不。他自己不能来——周明远在监视他的一举一动。他通过安全渠道传给我的。"

陆辰接过芯片。三个密钥片段——方云深、陆远征、韩墨白。三个人，在十年前一起创建了这些信标，然后各自隐藏。

方云深失踪。陆远征去了太空。韩墨白留在苍穹，做了首席架构师，沉默了十年。

"遗产里是什么？"他问。

"我不知道。"苏晚晴摇头，"但我知道一件事——方云深在失踪前的最后一条日志里写了一句话。"

"什么话？"

"'苍穹不是我们以为的东西。我需要让所有人知道真相。'"

苏晚晴的声音在安静的走廊里回荡。

"所以，陆辰——你准备好知道真相了吗？"

走廊尽头的天窗外，苍穹防护网的蓝色光膜一如既往地流动着。

但此刻它看起来不再像保护。

更像是一场审判的幕布。
